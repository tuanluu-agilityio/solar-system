# T18: Earth, Venus atmosphere, Saturn and Uranus rings

## Status

## Summary
- `src/bodies/earth.ts`: `createEarthMaterial` (ShaderMaterial: day map lit by N.L from the sun position, night-lights map on the dark side fading through a smooth terminator band, thin blue scattering rim on the lit limb), `createCloudLayer` (transparent shell at radius x 1.01, depthWrite off), `createAtmosphere` (additive back-side Fresnel shell at radius x 1.04, brighter on the sunlit side).
- `src/bodies/rings.ts`: `createRing` builds a `RingGeometry` rotated into the equatorial (XZ) plane with u remapped 0 (inner) to 1 (outer); ShaderMaterial, DoubleSide, transparent; optional texture (else a plain faint band); analytic planet shadow (ray toward the sun vs. the planet sphere) gated by a `uShadow` uniform.
- `src/scene/solarSystem.ts`: Earth uses the day/night shader plus clouds (spun 1.2x Earth's rotation) and a `#4da6ff` atmosphere (1.0); Venus uses `venus_atmosphere` as its surface map (falls back to `venus_surface`) plus a pale-yellow `#ffe9b0` atmosphere (0.6); Saturn ring 1.24r..2.3r with `saturn_ring`; Uranus ring 1.6r..2.0r, no texture, opacity 0.12, in Uranus' tilt group. `setTierSettings` toggles atmosphere visibility and the Saturn ring shadow.
- `src/bodies/planet.ts`: `createPlanet` takes an optional material override (used for Earth).
- `src/debug/e2eApi.ts` + `src/main.ts`: temporary `?e2e=1&debugCam=<bodyId>` close-up camera for screenshot checks (to be removed in Task 21).
- `tests/unit/earthRings.test.ts`: 13 tests covering the four factories, the solar-system wiring, tier flags and `debugCamTarget`.

## Decisions
- DECISION: Saturn ring opacity is 0.9 (the plan gives no number); translucency comes mostly from the texture alpha.
- DECISION: Venus atmosphere colour is `#ffe9b0` ("pale yellow" in the plan).
- DECISION: `makeFallbackTexture` marks its textures with `userData.isFallback = true` (checked via `isFallbackTexture`). The cloud layer is omitted when `earth_clouds` is absent or a fallback, because the solid fallback colour would be an opaque shell hiding Earth.
- DECISION: when `saturn_ring` is a fallback, Saturn gets a plain untextured band at opacity 0.35 instead of an opaque solid disc.
- DECISION: atmospheres are always built and hidden via `visible` when `atmosphere=false`, so runtime tier changes (Task 27) can toggle them without rebuilding.
- DECISION: clouds and atmosphere shells use the tier's sphere segment count at creation and are not rebuilt on `setTierSettings` (only the planet geometry is); acceptable cost difference.
- DECISION: the sun is assumed at the world origin (`SUN_WORLD_POS`), passed to the Earth material and used as the default in atmosphere/ring shaders.
- DECISION: rings are unlit (texture colour only, darkened by the analytic shadow); only Saturn's ring receives the shadow, the faint Uranus ring does not.
- DECISION: `createCloudLayer` and `createAtmosphere` take an optional trailing `segments` argument (default 64); the planned signatures are otherwise unchanged.
- DECISION: `debugCam` accepts any body id (not only `earth`) so Saturn, Uranus and Venus could be checked too; it only works with `e2e` in the query.
