# T39: Photorealistic enhancement

## Status

Implemented on `feat/t39-cinematic-enhancement`; PR opened at the user's request. Details and
known limits: `docs/ENHANCEMENT_PLAN.md`, `docs/IMPLEMENTATION_STATUS.md`.

## Summary

- t39a deep space: procedural starfield, baked star-free Milky Way glow and nebula, dust.
- t39b Sun: plasma photosphere, limb darkening, layered corona, prominences; bloom retuned.
- t39c planets: shared per-body shader, upgraded Earth (normal, specular, cloud shadows, city
  lights), lit rings with mutual shadows, small-rock asteroid belt.
- t39d interface: design tokens, SVG icons, settings popover (time speed, orbits, labels,
  quality with `ultra`), body navigator, grouped info panel with atmosphere row, UI sounds.
- t39e moons: Phobos, Deimos, Io, Europa, Ganymede, Callisto, Enceladus, Titan; Kuiper belt.
- t39f camera: keyboard navigation, zoom and rotate steps, idle drift, flight arc.
- Software renderers use the low shader detail and particle counts (`softwareFallback`).

## Decisions

- DECISION: one integration branch with local sub-task merges and a single PR.
- DECISION: moon maps are USGS Astrogeology public-domain mosaics; Deimos is generated and
  credited as simulated.
- DECISION: bloom is strength 0.42, radius 0.55, threshold 0.9 with a soft knee in every tier.
- Further `DECISION:` lines are in `docs/ENHANCEMENT_PLAN.md` section 9.
