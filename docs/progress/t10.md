## Decisions
- DECISION: Every transition into `flying` (START, GAP_ELAPSED, RESUME, NEXT, PREV) emits `flyTo(stop)` then `showPanel(focus === 'overview' ? null : focus)`. NEXT/PREV put `stopNarration, cancelGap` before those two. START emits no `cancelGap`.
- DECISION: Finishing (GAP_ELAPSED on the last index) emits `[autoOrbit(false), showPanel(null)]`, in that order.
- DECISION: START works from `idle` and from `finished` (a restart at index 0). It is ignored while a tour is active or paused, and when `total <= 0`.
- DECISION: PAUSE behaves exactly like USER_INTERACTED (pause from `flying|narrating|gap`). Both are ignored in `idle`, `finished` and `paused`.
- DECISION: NEXT/PREV work from `flying|narrating|gap|paused`, clear `pausedFrom`, and are ignored in `idle|finished`. NEXT on the last stop clamps and re-flies it; it does not finish the tour.
- DECISION: EXIT from any non-idle state, `finished` included, returns `initialTour(total)` with `[stopNarration, cancelGap, autoOrbit(false)]`. EXIT in `idle` is a no-op.
- DECISION: An ignored event returns the same snapshot object (reference equality) and `[]`. A missing stop for a valid index throws, which surfaces a broken stop list.
- DECISION: `shouldAutostart = !tourSeen && (!isE2E || forceAutostart)`. `forceAutostart` only overrides the E2E suppression and never overrides `tourSeen`. This keeps the "autostart once" invariant.
