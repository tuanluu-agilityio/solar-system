## Status
Done (pending review). The workflow is written and the build it runs passes locally. The first real deploy runs when this PR merges to `main`.

## Summary
- `.github/workflows/deploy.yml`: triggers on push to `main` and on `workflow_dispatch`. Permissions are `pages: write`, `id-token: write`, `contents: read`. Concurrency group `pages`.
  - Job `build`: checkout, setup-node 24 with npm cache, `npm ci`, `npm run lint && npm run typecheck && npm test`, `npm run build` with `BASE_PATH: /${{ github.event.repository.name }}/`, then `actions/upload-pages-artifact` (path `dist`).
  - Job `deploy` (needs `build`): environment `github-pages` with `url` from the `deploy-pages` output, then `actions/deploy-pages`.
- No TTS or texture fetching: the assets are committed, so CI needs no network beyond npm and GitHub.
- Pages was enabled for Actions builds by the controller with `gh api -X POST repos/tuanluu-agilityio/solar-system/pages -f build_type=workflow`. This task did not call the Pages API.

## Decisions
- DECISION: `actions/checkout@v4` and `actions/setup-node@v4` keep the same majors as `ci.yml`. The latest releases are higher (checkout v7.0.1, setup-node v7.1.0), but the task asked for the same majors as CI. Upgrade both files together later.
- DECISION: `actions/upload-pages-artifact@v5` and `actions/deploy-pages@v5` are the latest majors (v5.0.0 and v5.0.1, checked with `gh api`).
- DECISION: the workflow has two jobs, `build` and `deploy`, not one job with steps. The `github-pages` environment and the `page_url` output belong to the deploy job, and this keeps the Pages token scope to the deploy step only.
- DECISION: `concurrency.cancel-in-progress` is `false`, so a run already deploying to Pages is never cancelled by a newer push. Newer runs queue behind it.
- DECISION: Pages was enabled by the controller with `gh api -X POST .../pages -f build_type=workflow`. The controller reported the POST as the enabling call. This task did not verify it and did not need the `HUMAN_REVIEW.md` fallback.
- DECISION: the first deploy runs when this PR merges to `main`. The site is https://tuanluu-agilityio.github.io/solar-system/.
