## Summary

- DECISION: Moon uses its own label key `field.distanceEarth` (the `field.distance` label says "from the Sun"); the Sun and Moon thus have no `field.distance`.
- DECISION: order line is `{kind} #{n}` / `{kind} thứ {n}` using the content `kindLabel` (e.g. "Terrestrial planet #4"); no order for the Sun, Moon, belt.
- DECISION: a tap (< 8 px) on the sheet handle also toggles peek/expanded, for non-drag users.
- DECISION: sheet heights use `dvh` with a `vh` fallback.
