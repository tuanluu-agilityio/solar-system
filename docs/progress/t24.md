## Summary
- `src/ui/infoPanel.ts`: `panelFields(def, lang)` (omits undefined fields, formats units) and `createInfoPanel(root, store, onBack)`. One `aside[data-testid=panel]` with `data-layout` (mobile/desktop) and `data-state` (peek/expanded); content set with `textContent` only. Re-renders on `lang`, `selected`, `layout`. - `src/i18n/strings.ts`: `unit.*`, `field.distanceEarth`, `panel.order`, `panel.facts` in vi and en.
- `src/ui/styles.css`, `src/main.ts`: styles and wiring (`onBack` = `backToOverview`).
- Tests: `tests/unit/infoPanel.test.ts`, `tests/e2e/panel.spec.ts` (placement per layout, lang switch retitles panel, back, resize between layouts keeps selection).

## Decisions
- DECISION: Moon `distanceFromParentMkm` changed 0.384 to 0.3844 (and bodies test) so the panel shows the plan's `384,400 km`; the Moon orbit radius changes negligibly.
- DECISION: Moon uses its own label key `field.distanceEarth` (the `field.distance` label says "from the Sun"); the Sun and Moon thus have no `field.distance`.
- DECISION: order line is `{kind} #{n}` / `{kind} thứ {n}` using the content `kindLabel` (e.g. "Terrestrial planet #4"); no order for the Sun, Moon, belt.
- DECISION: a tap (< 8 px) on the sheet handle also toggles peek/expanded, for non-drag users.
- DECISION: sheet heights use `dvh` with a `vh` fallback.

- Note: the plan's NASA table row for the Moon (0.384) was refined to 0.3844 in code.
- Fix round 1: on mobile the infoPanel sets `data-sheet` (peek/expanded) on the root and CSS lifts `.not-to-scale` above the sheet; `render()` only rebuilds when selected/lang/layout change; duplicate mobile CSS blocks merged.
