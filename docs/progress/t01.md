# T01: Permissions, session-start hook, tracking docs

## Status
Done (implementation committed on `chore/t01-agent-permissions-hooks`; awaiting review and PR).

## Summary
Added `.claude/settings.json` with the allow/deny permission rules from spec 12.3 and the SessionStart and Stop hooks. Added `.claude/hooks/session-start.mjs`, a dependency-free script that prints a resume summary (newest plan, current task, recent progress, open PRs, worktrees, open known issues, branch and status) capped at 40 lines and always exiting 0. Added `docs/progress/README.md`, `docs/KNOWN_ISSUES.md`, `docs/BACKLOG.md`, ADR 0001, and extended `.gitignore`.

## Verification

- `.claude/settings.json` parses as valid JSON.

## Decisions
- DECISION: Step 1 (fetching the settings and hooks docs) was skipped; used the known current syntax (`Bash(cmd *)` rules, `WebFetch(domain:...)`, nested `hooks` arrays with `type: command`).
- DECISION: Bare-command git rules (`status`, `diff`, `log`, `branch`, `stash`, `init`) are listed both bare and with ` *` so they match with and without arguments; `commit`, `add`, `checkout`, `switch`, `show`, `rev-parse` use ` *`.
- DECISION: WebFetch allows both `nasa.gov` and `*.nasa.gov` to cover "nasa.gov subdomains".
- DECISION: Added `pip3 install *` and `python -m pip install *` to deny alongside `pip install *`; `.venv/Scripts/pip install *` is allowed and is a different command string, so the venv case stays permitted.
- DECISION: KNOWN_ISSUES entry template is an indented code block, not a `## ` heading, so the session-start hook does not list it as an open issue.
