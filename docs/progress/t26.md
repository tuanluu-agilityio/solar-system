## Summary
- `src/tour/tourController.ts`: `createTourController(deps)` feeds events to `tourReducer`, mirrors the snapshot into `store.tour` and applies the effects. `flyTo` -> `rig.flyTo(system.getFocusTarget(id))` or `rig.flyToOverview()`, then `FLIGHT_DONE` guarded by a flight generation counter (stale or superseded completions are ignored). `showPanel` -> `store.set({selected, view})`. `playNarration` -> `resolveSegment(manifest, stop, lang, script)`; with a recording and sound on it calls `audio.playNarration(url)` and advances on `'ended'`; on `'error'` it waits out the rest of `durationMs` on the clock with subtitles only (Review Focus 4); `'stopped'` is ignored. Muted or no recording: a `durationMs` timer, cues timed from `timers.now()`. A watchdog ends a clip that stalls after it started at `durationMs + NARRATION_LOAD_TIMEOUT_MS + NARRATION_STALL_GRACE_MS` (2000). `startGap`/`cancelGap` own one gap timer; `autoOrbit` -> `rig.setAutoOrbit`. `rig.onUserInteract` -> `USER_INTERACTED`; `store.lang` change -> `LANG_CHANGED`. Events raised while effects are applied are queued, so dispatch is never re-entrant. `currentCue()` returns the cue only while narrating. Constants `NARRATION_STALL_GRACE_MS`, `TOUR_AUTOSTART_DELAY_MS` (3000).
- `src/tour/scaledTimers.ts`: real timers with a speed factor and a continuous scaled clock; the e2e `setTimeScale(n)` drives it.
- `src/ui/tourControls.ts`: bottom-centre dock (`.tour-dock`, shared with the subtitles) with ⏮ / ⏸ / ⏭ / progress (`tour.progress`, "Stop 5 of 14") / ✕, `data-testid` `tour-prev|tour-pause|tour-next|tour-progress|tour-exit`, all `ctl-btn` (>= 44 px), labels via `t()`. Visible only while a tour is active. While paused the pause button becomes a prominent labelled "▶ Resume" button (class `tour-resume`). Marks `#app` with `data-tour="active"` (CSS hides the first-visit hint, which sat under the subtitles) and `data-panel="desktop"` (the dock moves right of the left panel).
- `src/ui/subtitles.ts`: caption (`data-testid="subtitles"`, textContent only, `aria-live`), updated every frame from `currentCue()`, touched only on change, hidden unless narrating. While the tour runs muted, a `tour.unmuteHint` button (`data-testid="tour-unmute"`) above it unmutes.
- `src/ui/styles.css`: dock, caption, controls; the dock sits above the mobile bottom sheet (`#app[data-sheet]`) and clear of the desktop panel.
- `src/main.ts`: loads `audio/narration/manifest.json` (null on any failure) in parallel with the textures; creates the controller after the solar system with a rig wrapper that adds the whoosh and the high-tier texture upgrade (shared `upgradeOnArrival`) to tour flights; the control-bar Tour button dispatches `START` (via `startTour`, which sets `sse.tourSeen`) or `EXIT`; a canvas `pointerdown`/`wheel`, a picker or label selection, the e2e `select`, and back to overview (panel button, sheet swipe-down, e2e `overview`) dispatch `USER_INTERACTED` first; autostart on the first ready frame when `shouldAutostart(tourSeen, isE2E, params.has('autostart'))`, after 3000 ms; subtitles updated in the loop; e2e `tour(e)` dispatches and `setTimeScale(n)` scales the tour timers and the rig dt.
- Tests: `tests/unit/tourController.test.ts` (13, fake timers, fake rig and audio), `tests/unit/scaledTimers.test.ts` (4), `tests/unit/tourUi.test.ts` (7, jsdom), `tests/e2e/tour.spec.ts` (4 x 3 projects).

## Decisions
- DECISION: `TourDeps` gains an optional `audioUrl(file)` (main prefixes `import.meta.env.BASE_URL`), so the controller stays free of Vite globals and the manifest is used as committed.
- DECISION: stall watchdog for a clip that started but never ends (T25 review note 4): `durationMs + 8000 (engine load timeout) + 2000`; the load timeout is included so a slow-starting clip is not cut short. On expiry it calls `audio.stopNarration()` and advances.
- DECISION: after a narration `'error'`, subtitles keep running on the clock from the stop's start, and the stop ends at `durationMs` from that start (Review Focus 4).
- DECISION: unmuting during a subtitle-only stop (e.g. via the unmute hint) restarts that stop with its recording, inside the same click (so playback is allowed). Muting during an audio stop lets the clip run on the muted master.
- DECISION: every manual camera or selection action pauses the tour (spec §3.8 "chạm/kéo/zoom"): canvas `pointerdown` (taps; camera-controls emits `controlstart` only for drags) and `wheel` (camera-controls emits no `controlstart` for the wheel), picker and label selection, the e2e `select`, and back to overview. The manual flight then supersedes the tour flight; the tour's completion is ignored (generation + paused state). Resume re-flies the current stop.
- DECISION: the "seen" flag is set by every tour start (button or autostart), not only autostart; the autostart timer is skipped if, during the 3 s wait, a tour was started, the user tapped, dragged or zoomed the scene, selected a body or went back, or a body is selected (`autostartStillWanted`, review fix round 1). The flag then stays unset, so the tour autostarts on the next visit. The autostart delay uses real time (not the e2e time scale).
- DECISION: the paused state shows the pause button itself as a prominent labelled "▶ Resume" button instead of a second resume button.
- DECISION: the e2e-only `setTimeScale(n)` scales the tour timers (narration, gap, subtitle clock) and the camera-rig dt (flights, auto-orbit); orbital motion keeps real time. Pending timeouts keep their delay when the scale changes. camera-controls' smoothing stays stable with a large dt.
- DECISION: tour flights also play the whoosh (spec §3.7: whenever the camera flies to a body or back) and load high-tier textures on arrival, through a rig wrapper in `main.ts`.
- DECISION: the unmute hint shows for the whole active tour while muted (not only while narrating), so it does not flicker between stops.
- DECISION: the narration manifest is fetched in parallel with the textures; any failure (404, bad JSON) yields `null` and the whole tour runs subtitle-only on estimated durations.
