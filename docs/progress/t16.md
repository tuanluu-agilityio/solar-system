# T16: Sun, light and bloom

## Status
Done (review approved).

## Summary
- `src/bodies/sun.ts`: `createSun(tex)` returns `{ group, light, update, radius }`. Radius = `displayRadius(BODIES.sun.physical.diameterKm)` (about 9.9). Surface is a `ShaderMaterial` that samples the sun texture with two horizontally scrolling UV offsets (different speeds), multiplies by two-octave 3D value-noise granulation and an HDR gain of 2.4. Additive corona sprite of radius x1.6 (procedural radial-falloff DataTexture). `PointLight` `#fff4e0`, intensity 3, decay 0; `AmbientLight` `0x223344` at 0.04. `update(tSec)` drives the `uTime` uniform.
- `src/scene/postfx.ts`: `createPostFX` = `EffectComposer` -> `RenderPass` -> `UnrealBloomPass` (1.2 / 0.6 / 0.85) -> `OutputPass`. Bloom buffers resized to drawing-buffer size x `bloomResolutionScale` after every `composer.setSize`, because the composer otherwise resizes all passes to full size. `setSettings` re-applies the bloom scale.
- `src/scene/bloomConfig.ts` (three-free): `BLOOM` constants and `bloomResolution()` helper, unit-tested.
- `src/main.ts`: adds the sun, calls `sun.update(tSec)` and `postfx.render()` in the loop (replaces `renderer.render`), resizes postfx on window resize; temporary overview camera at (0, 45, 130) looking at the origin.
- ADR `docs/decisions/0004-bloom-implementation.md`.

## Decisions
- DECISION: tone mapping is applied once by `OutputPass` (it reads `renderer.toneMapping` ACES and `outputColorSpace` sRGB); the scene renders into the composer's HalfFloat linear target where three skips tone mapping. The sun shader still includes `tonemapping_fragment`/`colorspace_fragment` so it stays correct if ever rendered straight to screen.
- DECISION: the sky's `toneMapped: false` no longer has an effect under the composer (sky is now ACES-tone-mapped by `OutputPass`); the screenshot shows stars still clearly visible, so no change to `sky.ts`.
- DECISION: sun surface gain 2.4 (HDR) so the orange photosphere's luminance exceeds the 0.85 bloom threshold; corona sprite colour `0xffb860`, opacity 0.85, falloff `(1-r)^2.2`.
- DECISION: PointLight intensity 3 with decay 0 (physically based lights need about PI for a fully lit Lambert surface); planets (later tasks) may retune.
- DECISION: scrolling is horizontal only (wrapS = Repeat) to avoid pole seams on the equirectangular map; the second layer samples at 2x horizontal frequency.
- DECISION: the sun's diameter comes from `src/data/bodies.ts` (body data only in `src/data/`); bloom constants live in `src/scene/bloomConfig.ts` because they are identical across tiers (not a tier quality number).
- DECISION: no separate temporary e2e was added: the existing `boot.spec.ts` already asserts `getState().ready === true` with zero console errors on all 3 projects after the composer is in the loop.
- DECISION: temporary overview camera (0, 45, 130) looking at the origin until the camera rig (Task 21).
- DECISION: formatted only the new files with Prettier (not `npm run format`); `src/main.ts` was already not Prettier-clean on `main` and was left as is apart from the edits.
