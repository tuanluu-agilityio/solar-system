## Decisions
- DECISION: the sun gets a BodyObject whose mesh is a hidden stand-in sphere at the origin (visuals, light and bloom stay in `createSun`), so `bodies` has 11 entries and the sun is pickable/focusable.
- DECISION: Earth uses `EARTH_YEAR_DAYS` (365.25) instead of the data value 365.2, so one orbit takes exactly 60 s (the data value left a 0.05 unit drift per year, above the 1e-3 test bound).
- DECISION: Moon tidal lock is a constant mesh yaw (PI) inside the rotating moon pivot, not `-orbitalAngle` as the plan literally says: the pivot already carries the mesh round, so a constant yaw keeps the same face toward Earth (pinned by a test). Same intent, correct maths.
- DECISION: low tier is detected via `pixelRatioCap <= 1.5` for 32 sphere segments, to avoid changing the `TierSettings` shape pinned by the Task 11 tests.
- DECISION: pick proxies are `MeshBasicMaterial({ visible: false })` meshes (still raycastable); they are children of the offset node so they do not tilt.
- DECISION: `getFocusTarget(id).object` is the body mesh (its world position is the body centre).
- DECISION: the plan applies both the real tilt (Venus 177.4, Pluto 122.5) and a negative rotation period, which visually double-counts retrograde spin. Followed the invariants literally; flag for the Task 28 visual review.
