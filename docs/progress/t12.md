## Status
Done locally on `feat/t12-texture-pipeline`; awaiting review, PR and CI (controller).

## Summary
`scripts/fetch-textures.mjs` downloads the Solar System Scope sources to `.cache/textures-src/` (3 retries, cached), converts them with sharp to WebP q=82 in `public/textures/{low,high}`, generates a procedural Pluto map, and writes `public/textures/manifest.json`. ADR 0003 and a BACKLOG line for Pluto added. Test: `tests/unit/textureManifest.test.ts`.

## Decisions
- DECISION: sky_2048 is 2048x1024 and sky_4096 is 4096x2048, both from `8k_stars_milky_way.jpg`; sky_2048 lives only in `low`, sky_4096 only in `high`.
- DECISION: The brief says "sky keys only in low"; the test treats sky_4096 as high-only (the 4096 file cannot be in `low` under the 2048 px limit).
- DECISION: Some "8k" sources (sun, jupiter, saturn) are really 4096 wide; `high` is never upscaled so they stay 4096. Uranus/neptune stay 2048 in both sets.
- DECISION: Pluto SVG uses feTurbulence noise, a blurred reddish equatorial band and a blurred heart path centred at x = W/2 (lon 180 deg in equirectangular layout); same file in both sets.
- DECISION: Manifest keys are sorted alphabetically for stable diffs.
