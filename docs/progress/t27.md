## Decisions
- DECISION: the plan lists only 4 files; added `isFlying()` to the camera rig so the monitor can skip camera transitions, and three e2e API helpers (`pixelRatio`, `downgradeQuality`, `asteroidCount`) so the downgrade apply path is e2e-testable on SwiftShader where the monitor is off.
- DECISION: sky and loaded textures are never swapped on downgrade, antialias stays as created (cannot change at runtime), `textureSet` only affects future high-res upgrades (they read the current store tier).
- DECISION: a skipped frame (hidden/transitioning) resets the monitor window so a window never spans a hitch; after a downgrade the monitor is reset so medium can still fall to low.
- DECISION: asteroid count in e2e is read from the root's InstancedMesh each call (belt.mesh can be swapped on growth).
