# Progress log

One file per task: `t<NN>.md` (for example `t01.md`). One file per task means parallel branches never conflict on the log.

Each file has these sections:

- **Status**: done, blocked, or in progress.
- **Summary**: one paragraph on what was built.
- **Verification**: short output of the verification commands.
- **Decisions**: `DECISION:` lines for anything the plan left unspecified.
- **Review**: the reviewer verdict.
