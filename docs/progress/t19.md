# T19: Asteroid belt

## Status
Done (review pending).

## Summary
- `src/bodies/asteroidBelt.ts`: `createAsteroidBelt(count, seed?)` returns an `InstancedMesh` of detail-0 icosahedra (scale 0.08-0.35, grey-brown flat-shaded `MeshStandardMaterial`). Radii are uniform in the display range of `ASTEROID_BELT_MKM`, heights are +-1.5 (bell-shaped, mean of three uniforms), random orientation, mulberry32 PRNG. `update(tSec)` spins the whole mesh at a 4.6-year orbit; `setCount(n)` sets `mesh.count`.
- `src/scene/solarSystem.ts`: belt created with the tier `asteroidCount`, added to the root, updated each frame, and resized in `setTierSettings`.
- `tests/unit/asteroidBelt.test.ts`: 5 tests (determinism, radius/height/size bounds, setCount, period, wiring).

## Decisions
- DECISION: `mesh` is exposed as a getter because growing beyond the allocated capacity swaps in a new `InstancedMesh` (same seed, so the first instances are unchanged); shrinking just lowers `mesh.count`. The swap is done in the parent, so callers must not cache `belt.mesh` across `setCount`.
- DECISION: default seed 1337; belt colour `#8a7a68`; the mesh has `frustumCulled = false` since its bounding sphere is not computed for instances.
- DECISION: the belt rotates about the world Y axis from phase 0 and is independent of the focus anchor (which tracks Earth's angle), as the plan only asks for the belt's own 4.6-year spin.
